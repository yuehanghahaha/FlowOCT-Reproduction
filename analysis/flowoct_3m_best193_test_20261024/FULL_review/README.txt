FULL projection review package
figures/: paired FULL mean projections, absolute errors, and one central B-scan per case.
projections/: raw float32 2D FULL arrays for independent metric checks.
full_metrics.json: per-case, aggregate and disease-group FULL metrics.
prediction.json, summary.json, per_case.csv: unchanged original test records.
The original 3D NPZ files and checkpoints remain on the server.
This package supports projection review and selected slice visualization, not a full 3D re-audit.
