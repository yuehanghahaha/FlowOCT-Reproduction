## 3. 论文与代码对应关系

论文依据：本地 `papers/FlowOCT_IJCAI2026.pdf`，正式来源：[IJCAI PDF](https://www.ijcai.org/proceedings/2026/0213.pdf)。以下是用于复现核对的差异摘要，不扩展为作者意图判断。

| 项目 | 论文正文 | 当前公开代码 | 影响 |
|---|---|---|---|
| wavelet维度 | 3.2节、Eq.(2)描述3D DWT | 主模型DWT_2D/IDWT_2D四带 | 不能仅凭当前代码推断论文没提出3Dwavelet |
| 源条件 | Eq.(6)/(12)含w0 | netG输入当前wavelet与t，无源OCT额外输入 | 条件设计是公开实现差异，不自动是新颖点 |
| 速度监督 | wavelet目标与结构mask | IDWT后图像ROI MSE | 目标空间/ROI规则需说明 |
| 结构目标 | 3D mask、频带mask | fake/real矩形bbox并集裁剪 | bbox不等于vessel foreground mask |
| 投影 | Eq.(17)预定义层范围 | 抽样slice max，无层边界 | 不能称为完整解剖分层投影 |
| RDCA | Eq.(15)深度候选 | 对称fake/real slice InfoNCE | negatives与归一化不同，未显式坐标 |
| 训练轮数 | 200 | 默认400 | 必须覆盖默认值并记录协议 |
| 权重 | β=.2、λProj=.5、λRDCA=.005 | 10Lv+.5L1+.005Lc+.1Lp | .1与.5×.2相符，但其它目标差异仍在 |
| 硬件 | 48GB vGPU | 用户6GB笔记本GPU | 不能推定默认尺寸本机可用 |
| 评价 | 全体/前景、LPIPS/FID、诊断 | 验证仅全体MAE/PSNR/SSIM | 还缺完整指标和下游协议 |

这些差异足以阻止“clone后用默认值即可复现整篇论文”的承诺。只拿相同患者数量和epochs也不能弥补方法/协议差异。

## 4. 已验证并单独修复的投影ROI错误

原模型中投影形状为 `(C,H,W)`，原索引只给两个切片，从而把y的边框用于C维。若y_min>0而C=1，返回空张量，L1均值变NaN。

本次构造离开第0行的视网膜样带状输入，运行一个完整模型训练步。原版四loss中仅proj_loss为NaN，总loss非有限；修正版保留通道维，四loss与总loss都有限，优化后参数也有限。这个例子中原版参数仍可能有限，不能进一步声称所有NaN loss都会立即污染参数；但优化目标已无效。

文件：

- `working/`：作者源码的独立副本，仅两处索引表达式改变。
- `working/LOCAL_FIX.json`：来源与更改记录。
- `patches/projection-roi.diff`：可审阅补丁。
- `tools/prepare_working_copy.py`：重建副本工具，已有working时拒绝覆盖。
- `tools/probe_projection_roi.py`：原/修正版的同输入、同seed探测。
- `artifacts/projection_roi_probe.json`：实际输出。

真实数据初步运行推荐用working目录。本补丁不补全论文方法，不调整其它科研协议；报告应命名为“public implementation + ROI indexing fix”。

## 6. 正式训练前怎样逐项关闭问题

优先次序：

1. 真实首个患者格式/物理轴/配准/非恒定crop。
2. 采用已验证ROI修复，逐batch确认各loss有限。
3. 清单独立且评价固定；保存真实shape/spacing。
4. 在1～2患者上过拟合，证明任务/监督可学。
5. train/eval、seed、完整checkpoint、准确计时。
6. 固定协议下运行baseline，多seed后再开展结构消融。

不要为了修复同时重写全部模型；每个会改变结果的修正都应该记录和验证，避免“修bug带来提升”与“方法创新带来提升”混淆。
